新增自动更新提醒：MAL 会在打开应用、重新回到应用或从桌面网页快捷方式进入时自动检测 GitHub 最新正式版本，发现更新会直接弹窗展示更新内容并引导下载，不再依赖用户手动检查。
优化安卓最近任务：减少 MAL 浏览器或桌面网页会话在最近任务列表中被自动移除的情况，并在重启或覆盖更新后刷新仍存在的桌面快捷方式定义。
完善 GitHub 备份与恢复：备份上传后增加 SHA-256 回读校验，恢复支持较大的 GitHub 备份文件，并补充网页、分类、图标、桌面快捷方式映射和基础设置的恢复链路；恢复后会刷新系统仍保留的桌面快捷方式定义。
新增备份频率选择：GitHub 云端备份和手机自动备份可分别选择每 6 小时、12 小时、每天、每 3 天或每 7 天。
新增自选手机备份位置：用户可通过系统文件夹选择器决定自动下载备份保存到哪里，并保留长期访问权限。
新增手机本地恢复：可以直接选择手机中的 MAL JSON 备份文件进行恢复。
